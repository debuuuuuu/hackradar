## Findings & Backend Gaps
1. **Phone-only save (`/phone`):** `PUT /api/me/prefs` validates all preferences (`validatePrefs`) and rejects partial payloads. As required by instructions, phone fields were kept inside Setup Step 1 rather than creating a failing standalone `/phone` route.
2. **Saved Events API:** There are currently no user-events endpoints (`GET/POST /api/me/events`) on the web server. Save buttons on Today and EventDetail are rendered disabled with tooltips and annotated with `// TODO(backend)`.
3. **Daily Mascot Quip Lines:** Currently drawn from a static pool in `Quip.tsx` with `// TODO(backend): replace with daily AI-generated lines`.
