# Groq as the main AI provider

_As of 2026-10-15. Sources: https://console.groq.com/docs/models, https://console.groq.com/docs/rate-limits_

## Verified (docs, 2026-10-15)
- Production models: `llama-3.3-70b-versatile` (131k context, 32k max out), `llama-3.1-8b-instant`,
  `openai/gpt-oss-120b`, `openai/gpt-oss-20b`. OpenAI-compatible API: `https://api.groq.com/openai/v1`.
- **No text-embedding model listed** → Groq cannot produce the `vector(768)` embeddings the schema reserves
  for "learn from saves" (features §4).

## Unverified (could not read from the docs page)
- **Free-plan limits** (requests/min, requests/day, tokens/day): the rate-limits page showed only Developer-plan
  numbers in the extracted text. Read them in the console (settings/limits) after signup. Earlier note: org-level caps.
- **Whether signup needs a card**: not stated. If Groq asks for a card, stop (₹0 / no-card rule).
- JSON mode on `llama-3.3-70b-versatile`: not confirmed; the adapter sends `response_format: json_object`
  only when asked, and callers must validate the reply.
- Privacy: whether free-tier prompts are used for training is **unverified**; only public event text is sent anyway.

## Consequences
- Summaries, scores and extraction can run on Groq (D-035). Embeddings: use the TF-IDF fallback (features §4)
  first; add Gemini embeddings later only if wanted.
