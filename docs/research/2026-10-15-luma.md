# Luma (luma.com, formerly lu.ma) as a source

_As of 2026-10-15. Tested from Pune with the HackRadarBot User-Agent._

## robots.txt
- `luma.com/robots.txt` (lu.ma redirects there): rules only for `Googlebot`; other agents unrestricted.
- `api.lu.ma/robots.txt`: `User-agent: * / Disallow: /insights/`.

## Terms of service (luma.com/terms, read 2026-10-15, no "last updated" date shown)
- "you must not access the Service by any means other than our publicly supported interfaces"
- Site Content: "users are prohibited from downloading, republication, retransmission, reproduction"
- → robots.txt allows it, but the terms limit access to *publicly supported interfaces*.

## What exists
| Endpoint | Auth | Result | Usable? |
|---|---|---|---|
| `api.lu.ma/search/get-results?query=` | needs login | 401 | No (no logged-in access) |
| `api.lu.ma/discover/get-paginated-events?query=hackathon&latitude=&longitude=` | none | 50 events, 49 hackathon-named, nearest first (3 in Pune) | **Not used**: undocumented, not a "publicly supported interface" |
| same with `discover_place_api_id` | none | keyword barely filters (6/50 hackathons in Mumbai) | No |
| without place/coords | none | geolocates by caller IP (would be US on GitHub runners) | No |
| `api.lu.ma/ics/get?entity=calendar&id=cal-…` (calendar iCal feed) | none | full ICS of a calendar's events (past + future), Luma event URLs | **Yes**: the subscribe-to-calendar feed |
- Luma "places" include Mumbai, Bengaluru, New Delhi; **not Pune**.
- Official Luma API needs a paid Luma Plus plan and manages your own calendars only → not an option (₹0 rule).
- **Unverified:** that the ICS URL above is exactly what Luma's "Subscribe" button hands out (it returns the same feed format).

  (`cal-U4MQY0loKFEqShK`), Devnovate (`cal-3XyuS65JPasgZ5y`), Builderbase Hackathons (`cal-wdFQbbJ0VZTU33E`),
  Hackathons with ProgramEarth (`cal-QdVQqmeiFADPQKH`), Codex Community (`cal-63UOFcweB97l2gc`), upGrad (`cal-47gRZs7qN5Iwv8p`).
- One-off Luma hackathons on personal calendars: leave to Phase 4 web-search discovery (link back to Luma).

## Data shape
- ICS gives SUMMARY, DTSTART/DTEND (UTC), LOCATION (address or event URL), URL. No registration deadline,
  no prize, no fee → Luma items show "happens <date>"; filter by keyword (hack/buildathon) and future dates.
