# Graphify: code knowledge graph for the repo (as of 2026-10-23)

**What:** open-source tool that maps a repo into a graph of files, functions, classes and their links, so coding agents can
query the map instead of re-reading files. Package `graphifyy` (double y; PyPI warns other `graphify*` names are not
affiliated), MIT, source github.com/Graphify-Labs/graphify. Sources: [PyPI](https://pypi.org/project/graphifyy/),
[install guide](https://codeconductor.ai/blog/graphify-installation-guide/).

**Cost:** free and local for code (tree-sitter parsing, no API calls). Docs, images and community names need an LLM backend
(API key or the Claude Code skill). Not a hosted service; nothing about users or events goes anywhere.

## What was done (2026-10-23, Debjit asked for it)
- Installed `graphifyy[sql]==0.9.83` with `uv tool install` (pinned two weeks back; releases ship almost daily, latest 0.9.94 on 2026-10-22).
- Added `.graphifyignore` (secrets and build output) on top of `.gitignore`, which graphify already respects.
- Ran `graphify extract . --code-only` then `graphify cluster-only . --no-label`: **1,109 nodes, 2,680 edges, 77 communities**
  from 144 code files (Python, TypeScript, SQL). 57 docs and 21 images skipped (need an LLM). Communities are unnamed.
- Most connected: `registerAuthRoutes()`, `query()`, `Digest`, `PoliteClient`, `EventRecord`.
- Committed `graphify-out/graph.json`, `graph.html`, `GRAPH_REPORT.md`, `.graphify_analysis.json`. Ignored: `cache/`,
  `manifest.json`, `.graphify_root` (holds the local folder path).
- Checked the output for home-folder paths, database URLs and webhook URLs: none found.

## Use
- `graphify query "how does unsubscribe work"` · `graphify explain "readUnsubscribeToken"` · `graphify path "A" "B"`
- Refresh after code changes (free): `graphify update .`
- Open `graphify-out/graph.html` in a browser for the picture.
